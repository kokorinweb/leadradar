# Сайт ремонтной компании

Одностраничный сайт компании по ремонту квартир, домов и офисов
в Набережных Челнах. Next.js 16, React 19, TypeScript, Tailwind 4.

Опубликован: https://kokorinweb.github.io/leadradar/

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # продакшен-сборка
npm run lint
```

## Где что лежит

| Путь | Что там |
| --- | --- |
| `src/content/site.ts` | весь текст сайта: заголовки, цены, отзывы, контакты |
| `src/components/` | блоки страницы, по файлу на секцию |
| `src/components/primitives.tsx` | контейнер, секция, кнопка, слот под фото |
| `src/app/globals.css` | токены палитры и типографики |
| `.claude/skills/` | скиллы, подключаемые к сессиям на этом репозитории |

Текст меняется в `src/content/site.ts`, вёрстку для этого трогать не нужно.

## Что нужно подтвердить перед запуском

Значения, обёрнутые в `todo(...)`, — заглушки. Найти все разом:

```bash
grep -n "todo(" src/content/site.ts
```

Под подтверждением: название компании, телефон, адрес, часы работы, стаж,
количество объектов, срок гарантии, все цены и коэффициенты калькулятора,
данные объектов и тексты отзывов.

Пока `DEMO_NOTICE` в том же файле равен `true`, над шапкой висит полоса
о том, что цифры на странице — заглушки. Снять её вместе с последней
заменённой заглушкой.

## Фотографии

Снимков в проекте нет. На их местах стоит `PhotoSlot` — он держит кадр
в нужных пропорциях и подписывает, что туда идёт. Заменяется на
`next/image` без изменения разметки вокруг.

## Чего на странице пока нет

- отдельные страницы объекта, всех работ и направлений: пункты меню ведут
  якорями по главной;
- блок команды — нужны реальные фотографии и роли;
- материалы с доставкой и рассрочка — добавлять, только если услуги
  действительно оказываются сейчас.

## Формы

Сайт собирается статически, поэтому заявка из калькулятора и форма внизу
никуда не отправляются. Для рабочих форм нужен обработчик на сервере или
внешний сервис приёма заявок.

## Публикация

`.github/workflows/pages.yml` собирает статический экспорт и публикует его
на GitHub Pages при каждом пуше в `main`. Переменная `GITHUB_PAGES=true`
включает `basePath: /leadradar` — без неё страница на Pages пришла бы
без стилей.
